课题组 ImageJ 门户（web 版）

建议使用 Chrome 或 Firefox 打开（官方仅在此两者测试过）。
首次打开约需 1 分钟加载运行时，之后二次打开通常数秒内可用（缓存生效）。
每个标签页是一个独立 ImageJ 实例，互不影响；关闭标签页前请先保存结果。

如何导入你的图像（正式使用必读）

打开 ImageJ.JS 后，三种导入方式任选其一： ① 菜单导入：File > Open / Import…，可选择本机文件或已映射的共享盘文件（推荐先把共享盘映射为本机盘符）； ② 拖拽 / 粘贴：把图像文件直接拖入页面，或复制图像后在页面 Ctrl+V； ③ 链接导入：用 ?open=<图片URL> 参数打开服务器上的图像。 处理结果请按下方「保存结果」说明导出。

保存结果（重要）

web 端保存请使用保存对话框（宏中无路径的 saveAs("Tiff")，或菜单 File > Save As）， 文件将下载到本机下载目录。不要让宏写死保存路径——那样文件会留在浏览器内部，你拿不到。

大文件请勿在 web 端打开

单文件解压后像素数据 > 2GB 的图像请走服务器端 L1 管线（bioformats2raw → OME-Zarr）， 再用 vizarr 查看产物。100GB 级为永久禁区（浏览器内存墙）。
管线使用方式：联系管理员提交任务（提交口径见内部 wiki；vizarr 查看入口在管线就绪后开放）。

快捷键提示

自定义快捷键不要使用 Ctrl 组合键（浏览器会拦截）；建议用单字母或 Alt 组合。
