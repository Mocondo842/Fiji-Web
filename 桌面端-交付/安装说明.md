# 桌面端交付说明（分支 B 收口版，替代早前草稿）

日期：2026-10-25 ｜ 环境：Fiji 2.18.0/1.54p99 + Bio-Formats 8.5.0 @ `C:\Users\sr123\APP\Fiji`（扁平布局）

## 1. 快捷化（B1，A+B 双轨已部署）

- **启动方式**：双击桌面「**启动Fiji(带按钮栏)**」→ Fiji 启动并自动装载 6 键 Action Bar（浮动按钮栏，屏幕顶部；也可从 `Plugins > ActionBar` 菜单手动开条）。
  - 机制：启动器旗标 `-macro …\macros\load_actionbar.ijm`（本版 Fiji 无 StartupMacros 钩子，勿再尝试该路径）。
  - **参数口径**：`run("Action Bar", 参数)` 只认相对 `plugins/ActionBar/` 的文件名，绝对路径被静默忽略。
- **Action Bar 插件**：经 Fiji 更新器从 Mutterer 官方站点安装（`plugins/action_bar.jar` 2023-09，db 受管）。**升级走更新器，禁止手动拷 jar**（本版不注册手动文件）。
- 按钮栏定义：`plugins/ActionBar/my_tools.ijm`（5 键，与宏库 01–05 一一对应；按钮体只含样例自举+一行 run，业务逻辑永远在宏库）。
- 宏库单一来源：`C:\Users\sr123\ijweb\macros\{common,desktop,web}`，镜像入库 `部署-overlay/macros`。
- 新宏流程（≤10 分钟）：写宏 → headless `-batch` 验证 → 入库 → `my_tools.ijm` 加一按钮 → 重启 Fiji。
- 快捷键：如需绑定，GUI 里 `Plugins > Shortcuts > Add Shortcut`；**不用 Ctrl 组合**。

## 2. 批处理（B2，已验证）

`ijweb\headless\batch_run.py`：改文件头三个路径常量后：
`fiji.bat --headless --console --run C:\Users\sr123\ijweb\headless\batch_run.py`
- 规则（BR3/BR4）：每文件一行 CSV（file,status,seconds,output_or_error）+ SUMMARY 行；单文件失败不中断；输出目录分离、`_out.tif` 后缀、不覆盖。
- 实测：10 混合格式文件（含 1 损坏件）→ ok=9/fail=1，0.1–0.6s/文件。
- 默认处理动作 `Invert`（脚本头 `PROCESS` 常量可改命令名）。

## 3. 大文件管线（B3，已验证 + 拖拽入口）

- **日常用法（拖拽）**：把显微文件（czi/ims/nd2/tif…）**拖到桌面「转OME-Zarr」图标** → 源文件旁生成 `<同名>.ome.zarr`（5 级金字塔；1.66G 样本实测 2 分钟；内存 12G 上限，>10G 文件先经负责人确认）。
- **查看**：Fiji 里 `File > Import > HDF5/N5/Zarr/OME-NGFF ...` → 选择 `.ome.zarr` 目录打开（注意：菜单项全名如此，没有单独叫 "N5" 的项）。
- 手工命令行：bioformats2raw 0.13.0 @ `ijweb\b2r\`（需 `JAVA_HOME`=Fiji 的 Zulu21、`JAVA_OPTS=-Xmx12g`）。
- 实测产物：`E:\wx\zarr_out\14766.ome.zarr`（level0 = T100×C2×Z1×2304²，uint16）。

## 5. 已知坑（历史登记，防复发）

- 宏内 `getDateAndTime()` 返回数组，字符串拼接抛错且在启动路径被静默吞——日志时间戳禁用它；
- 启动宏/按钮栏宏 ASCII-only（ij1 按 GBK 读）；
- 本版 Fiji 不注册手动拷贝的 jar/宏文件（一切插件走更新器）；
- `fiji.bat` 的 Java stdout 不可见——一切输出走 `File.append` 落盘。
