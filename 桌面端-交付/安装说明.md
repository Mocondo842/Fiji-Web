# 桌面端 Fiji 交付说明（阶段 1）

日期：2026-10-25 ｜ 状态：**待实机复核**（本部署机未安装桌面 Fiji，S3 的桌面部分按「交付待验」处理）

## 1. 包内容

- `Fiji.app/plugins/ActionBar/my_tools.ijm` — Action Bar 按钮栏配置（官方 `<line>/<button>` + `label/arg` + `arg=<macro>` 块语法，与 web 端三个 common 宏一一对应）
- 宏库单一事实来源在部署机 `C:\Users\sr123\ijweb\macros\`（common / web / desktop），web 端经 `dist\macros\` 镜像对外服务

## 2. 安装步骤（桌面 Fiji）

1. 把 `my_tools.ijm` 放入 `Fiji.app/plugins/ActionBar/`（文件名带下划线，Fiji 约定）。
2. 重启 Fiji，`Plugins > ActionBar > my_tools` 出现按钮栏。
3. 开机自动加载（二选一，官方推荐前者）：
   - `Edit > Options > Startup...` 中填入：`run("Action Bar", "/plugins/ActionBar/my_tools.ijm");`（ImageJ ≥1.49e）
   - 或在 `StartupMacros.txt` 的 AutoRun 里加同一行

## 3. 与宏库的同步（避免第二份脚本）

本版按钮为**内联回退形态**（`arg=<macro>` 直接含逻辑），保证任何机器开箱即用。
按技术文档 §5.3.3 的目标形态，正式使用时把 `arg=<macro>` 内容替换为一行
`runMacro("//<服务器共享路径>/macros/common/01_stack2images.ijm");`
指向宏库的共享盘路径（**待确认：共享盘 UNC 路径**——待确认事项，与 R9 端口一起找 IT 定）。

## 4. 快捷键

如为按钮配快捷键：不用 Ctrl 组合（与 web 端同规则，桌面端避免与系统冲突）；建议单字母或 Alt 组合。
