# Fiji-Web — 基于 web 浏览的 Fiji/ImageJ 与快捷插件工程

一台部署机 + 局域网多设备浏览器访问的 ImageJ 方案，配套双端（web/桌面）共用宏库与快捷化体系。
大文件（>2GB）与重计算按边界走 headless 管线（见《方案调研》），web 端定位为轻交互前端。
